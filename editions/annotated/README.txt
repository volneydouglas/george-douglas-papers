GEORGE DOUGLAS PAPERS — ANNOTATED REFERENCE EDITION
Version 2.0 package, 26 September 2026

Eight searchable PDFs and eight editable Word files account for all 932
scan pages in ten source PDFs. Volumes I–IV retain version 1.1; V–VIII
add Folder 4, the daybook, Folder 6 and the poems in Folder 7.

Start with README.md for the volume list and Supporting-files/Editorial-guide.md
for the current scope, method and uncertainty conventions. The narrower
scope in the unchanged Volume I describes the earlier edition.

For offline searching open Supporting-files/Complete-transcript.html.
Supporting-files/Unresolved-readings.html links 3,415 uncertain readings
to transcript blocks. The matching TSV supports review and corrections.
Supporting-files/PDF-page-map.tsv gives the starting PDF page for each
source scan; entries may continue onto following pages. Reusable text,
JSON, source checksums and a page inventory are also in Supporting-files.

All new pages received an AI visual reading. This is not an independently
human-verified or ACU-endorsed edition. The source scans remain the
authoritative evidence and are not copied into the package.

Review-summary.txt describes current checks. Review-summary-v1.1.txt and
earlier audit files retain their historical scope. Draft-cover-note.txt is
an unsent suggested message. RIGHTS.md explains publication and reuse.

manifest.txt lists files; SHA256SUMS.txt checks every file except itself.
